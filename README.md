# Multi-Game Draft Bot

This repository contains the code for the **Multi-Game Draft**, a web-based platform inspired by the concept of "Play At :- [AnimeDuel.in](https://www.animeduel.in/)". The system allows users to draft characters from different franchises (anime, Pokemon, Marvel, etc.) and compete in various multiplayer game modes. It provides an engaging, interactive experience mirroring the online draft game linked above.

## 🚀 Features

- **Character Drafting**: Users can pick characters from multiple universes and build their rosters.
- **Multiplayer Mode**: Play against other users in real time via the web server component.
- **Plugin Architecture**: Easily extend functionality with plugins for commands, callbacks, admin tools, and game logic.
- **Data Management**: Includes JSON datasets for characters, Pokémon, Marvel heroes, and more.
- **Web Interface**: A minimal web server to host the game frontend and handle requests.



## 🛠 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 📦 Deployment

The project can be deployed to any Python-friendly hosting environment. The example URL uses Vercel's Python serverless functions. Ensure environment variables and port settings match your hosting provider.

## 🎮 How to Play

1. Open the website.
2. Join a draft session or create your own.
3. Take turns selecting characters.
4. Once the draft fills up, begin the game and compete for points.
